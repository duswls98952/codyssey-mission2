# 🧁베이킹 이모저모

## 프로젝트 개요

이 프로젝트는 Python으로 만든 콘솔 기반 베이킹 퀴즈 게임입니다.
사용자는 메뉴에서 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록 확인, 점수 확인, 종료 기능을 선택할 수 있습니다.

Python 기본 문법, 클래스, 반복문, 조건문, 예외 처리, JSON 파일 저장을 연습하기 위해 제작했습니다.

## 퀴즈 주제 선정 이유

베이킹은 재료, 조리 과정, 이름의 유래처럼 퀴즈로 만들기 좋은 정보가 많습니다.
익숙한 디저트를 주제로 퀴즈를 만들면 흥미를 가지고 문제를 풀 수 있다고 생각했습니다.

## 실행 방법

```bash
python3 main.py
```

프로그램을 실행하면 메뉴가 출력됩니다.
번호를 입력해 원하는 기능을 선택할 수 있습니다.

## 기능 목록

1. 퀴즈 풀기
   - 저장된 퀴즈를 순서대로 풉니다.
   - 정답 / 오답 여부를 확인할 수 있습니다.
   - 모든 문제를 풀면 점수가 출력됩니다.

2. 퀴즈 추가
   - 사용자가 직접 문제, 보기 4개, 정답 번호를 입력해 퀴즈를 추가할 수 있습니다.
   - 추가한 퀴즈는 `state.json`에 저장됩니다.

3. 퀴즈 목록
   - 현재 저장된 퀴즈 목록을 확인할 수 있습니다.
   - 퀴즈가 없는 경우 안내 메시지를 출력합니다.

4. 점수 확인
   - 최고 점수를 확인할 수 있습니다.
   - 퀴즈를 풀 때마다 최고 점수가 갱신됩니다.

5. 파일 저장 / 불러오기
   - 퀴즈 목록과 최고 점수를 `state.json`에 저장합니다.
   - 프로그램을 다시 실행해도 저장된 데이터가 유지됩니다.
   - 파일이 없거나 손상된 경우 기본 퀴즈로 시작하거나 복구합니다.

## 주요 파일 설명

### main.py

퀴즈 게임의 전체 코드가 들어 있는 파일입니다.

포함된 주요 구성:
- `Quiz`: 퀴즈 한 문제를 표현하는 클래스
- `QuizGame`: 게임 전체 흐름, 퀴즈 목록, 최고 점수, 저장 / 불러오기를 관리하는 클래스
- 메뉴 입력 처리 함수
- 정답 입력 처리 함수
- JSON 저장 / 불러오기 로직

### state.json

퀴즈 데이터와 최고 점수를 저장하는 JSON 파일입니다.
프로그램 실행 중 퀴즈를 추가하거나 점수가 갱신되면 이 파일에 저장됩니다.

### docs/development.md

개발 과정, 요구사항별 작업 내용, 검증 내용, 실행 결과 스크린샷을 정리한 문서입니다.

### docs/screenshots/

개발 환경, Git 기록, 프로그램 실행 결과를 증빙하는 스크린샷이 저장된 폴더입니다.

## state.json 데이터 구조

```json
{
  "quizzes": [
    {
      "question": "문제 내용",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2
    }
  ],
  "best_score": 0,
  "has_played": false
}
```

- `quizzes`: 저장된 퀴즈 목록
- `question`: 문제 문장
- `choices`: 보기 4개
- `answer`: 정답 번호
- `best_score`: 최고 점수
- `has_played`: 퀴즈를 푼 기록이 있는지 여부
